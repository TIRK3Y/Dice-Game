# Dice Game

A simple two-player dice game that runs in the browser. Each time the page loads, both players get a random roll from 1 to 6. The page shows the matching dice images, and the heading announces the winner or a draw. It is a beginner project for practicing DOM manipulation with vanilla JavaScript.

## Features

- A random roll for each player on every page load
- Dice faces drawn from six images
- Heading updates to show which player won, or a draw

## Tech stack

- HTML5
- CSS3 (Google Fonts: Indie Flower and Lobster)
- Vanilla JavaScript

## Getting started

No installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/TIRK3Y/Dice-Game.git
   ```
2. Open `index.html` in a web browser.

## Usage

Refresh the page to roll the dice again. The higher number wins, and equal numbers are a draw.
